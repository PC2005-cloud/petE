# 大肥鱼的一天 · dsh-pet-fish-day

dsh-pet 的第三方扩展：右键宠物 → **更多 → 大肥鱼的一天**，它会按**一天的日程**演下去——
起床、三餐、工作、午休、晚上娱乐、睡觉；碰上节日或换季，日程里还会多出对应的事件。

不新增任何素材：动画全部复用 dsh-pet 现有的，扩展只负责“什么时候播哪一段、说什么、要不要挪个位置”。

## 安装

```powershell
dsh plugin --profile web add "github:PC2005-cloud/petE#path:/fish-day"
```

图形化页面：DSH Web → 侧栏「插件」→「添加插件」，粘贴 `github:PC2005-cloud/petE#path:/fish-day`。

前置：`dsh-pet` 已在同一个 profile 启用；宠物显示在网页或桌面都行——菜单两端都有，接口用 `surface=any` 发指令。

## 怎么用

| 想干什么 | 怎么做 |
| --- | --- |
| 开始一天 | 右键宠物 → 更多 → 大肥鱼的一天 |
| 提前收场 | 拖一下宠物（占用锁被撤，当场结束） |
| 重新来一天 | 再点一次菜单 |

推演的节奏由事件表决定：每段动画都有自己的台词——气泡和动画**同时开始**，动画播完才进入下一段，
所以屏幕上不会出现“只有动作、没有台词”的空档。需要挪位置时，走一段移动动画。
走到最后一场（晚安）自然结束。

## 移动

移动不自己推坐标，而是播 dsh-pet 的**移动类动画**（`螃蟹走路` / `原地漂浮踏步` / `原地左转奔跑`）：
dsh-pet 的移动系统会接管这一段，按素材自己的 `leadSec` / `tailSec` 在原地等完首尾，中间才真的位移。
所以走起来有走路动作，不是贴着地面滑过去。

## 一天里有什么

- **固定日程**：起床洗漱、早中晚三餐、上午与下午的工作、午睡、摸鱼、下午茶、下班、晚上的娱乐与才艺、睡前；
- **节日**：春节、元宵、清明、端午、七夕、中秋、重阳、腊八、圣诞、万圣——按真实日期判断
  （农历用浏览器的中文历法计算）；
- **季节**：春天放风筝、夏天吃西瓜、秋天被落叶埋、冬天堆雪人；
- **随机插曲**：每个事件之后有一定概率插入一段别的动画（变鸽子、蓝鲸现世、玩魔方……）。

## 覆盖策略

dsh-pet 的动画池有一百来个，一场演不完。扩展用 shuffle bag 记录“已经演过哪些”，
进度存在 `sessionStorage`，下一场优先补没演过的——两三场就能覆盖全部。

## 想改点什么

- **日程**：`lib/client.js` 顶部的 `SCHEDULE`（时刻、动画序列、台词、是否移动）；
- **节日**：同文件的 `FESTIVALS`，农历用 `[月, 日]`，公历用 `{ solar: [月, 日] }`；
- **插曲池**：`RANDOM_POOL`；
- **节奏**：`CFG`（气泡时长、事件间隔、移动速度、插曲概率）。

动画名必须与 dsh-pet 动画池里的名字完全一致（名字即文件名），写错会被接口拒绝并跳过。
